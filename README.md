# Portfolio Website

A modern, animated personal portfolio built with React, TypeScript, Tailwind CSS, and Framer Motion.

🔗 Live: [rutra.me](https://rutra.me)

## Features

- **About** – skills and tools grouped by category (languages, frameworks, infrastructure, AI/APIs)
- **Projects** - searchable/filterable project grid with a detail dialog (media carousel, tags, achievements)
- **Achievements** - competition results with tiered styling (gold/silver/bronze)
- **Contacts** - quick links to email, LinkedIn, and GitHub
- Smooth page/section transitions and micro-animations throughout
- Responsive layout with a mobile slide-out nav drawer

## Tech Stack

- [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/) - animations
- [Lucide React](https://lucide.dev/) / [React Icons](https://react-icons.github.io/react-icons/) - icons
